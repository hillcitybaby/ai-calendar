How it moves

The rules behind the motion. They carry over to the code build.

  • Every particle has a spotEach state gives every particle a place inside the shape. Particles steer toward their spot; nothing jumps.
  • They travel togetherA shared current bends their paths, so neighbors move in the same sweeping bands, like a flock.
  • Shapes stay aliveInside a shape, particles keep circulating slowly: a swirl in the circle, a current around the donut, loops inside the square.
  • Changes ripple acrossWhen the state changes, particles leave over about half a second, one side first, so the change reads as a wave. With reduced motion, each state is a still shape.
